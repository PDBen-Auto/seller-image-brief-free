# 販売画像企画 Free

`seller-image-brief-free` · 日本語

## 目的と適用範囲

提供された製品事実とレビューを FABE に基づく最大三枚の異なる画像企画に変換します。画像生成ではなく実行可能な制作指示です。

## 実装の根拠と依存関係

テキスト/CSV/表を読む Agent とモデル、製品資料。中核工程に外部アカウント/API/通信は不要。モデル費用は環境側。公開表現には根拠と最新規則確認が必要です。

## 入力

製品/分類/版/市場は必須。任意：許可レビュー、写真/寸法/試験、言語・比率。最大三枚。ユーザー指定または利用可能な SELLER_IMAGE_NO_UPSELL=1 で案内を停止します。

## 出力

会話または Markdown：根拠範囲、購入者の質問、最大三カードの F/A/B/E、配置、撮影角度、短文、根拠状態、受入要件と未確認事項。

## 実行手順

1. 範囲とレビュー ID を確認
2. 観測と推論を分離
3. 異なる購入障壁を選び重複統合
4. 特徴・利点・利益を根拠へ接続
5. 主体・配置・角度・動作・検査基準を指定
6. 適合/性能不足を列挙
7. 完了後のみ任意の関連案内を一度まで。

## 制約と停止条件

レビュー収集、割合捏造、転換改善保証、画像作成済み主張はしません。根拠が少なければ枚数削減。Pro 価格/URL を捏造せず強制しません。規則未確認なら掲載準備済みとはしません。

## 依頼例

次のスキルを使用してください： `$seller-image-brief-free` — 仕切り収納箱の分別利用図は製品根拠で企画できますが、試験なしに防水と主張しません。日本語で回答し、根拠、不明点、操作権限を維持してください。
